# 玖玖の小屋 · Jiujiu's Atelier

## Editorial Edition IV · 克制的杂志式排版（2026-11-07）
- `assets/editorial-v4.css` 是全站统一的编辑视觉层：奶白纸张、清晰的字体层级、纤细分隔线、稳定的响应式网格，以及完整的暗色方案。
- 首页重新整理导航、首屏留白、章节索引、项目陈列、灵感筛选、互动入口和创作手记。保留现有 SVG 纸雕、小镇、解谜、明信片、便签等功能，不将参考网站内容照搬进来。
- 在手机和平板上使用单独的折叠菜单与无横向溢出的单列排版；动画以 transform/opacity 为主，支持系统减少动态效果设置。
- `assets/site.js` 的灵感筛选只绑定分类栏中的按钮，避免与页面的其他小按钮发生误操作。
- 该版已提交 GitHub `main` 分支。Cloudflare Pages 是否发布成功，以及最终手机端视觉效果，仍需线上实际检查。


一个轻量、可交互的个人作品小屋。静态网页，不需要打包工具或后端。

## Atelier III · 雕塑式纸艺视觉
- `assets/atelier-v3.css`：统一的杂志感纸雕视觉、雾紫及奶白的日间主题与完整夜间主题、卡片与导航设计。
- `assets/atelier-v3.js`：主视觉 SVG 多层纸景使用 requestAnimationFrame 惯性视差；离开指针后停止，手机和减少动态效果模式下不运行视差。
- 纸雕夜景使用 SVG 透明度动画，避免持续动画整幅画面的滤镜；保留敲门、日夜交互和既有作品内容。
- 本版主要是视觉与动效重制，不代表已经完成 Cloudflare Pages 的线上视觉验收。

## 纸雕视觉
- `assets/paper-cut.css`：韩系柔和纸雕主题；多层纸片、纸屑纹理、手工纸条导航和叠纸展示板。
- 首页纸景盒可以切换昼夜、敲门翻出通往解谜故事的纸片；兼容手机与减少动态效果。
- 视觉主要用 CSS 手工绘制，暂未接入单独的原创绘画文件。

## 小镇漫游与创作手账
- `world.html`：独立纸雕小镇地图（六个地点，点击展开真实作品入口）、日夜切换、个人纪念护照、集齐印章信件、私人心愿纸条盒。手机可以横向滚动地图。
- `assets/additions.css`：首页新增小镇纸景入口、四张具体创作档案展签和移动端适配。
- 浏览器 `localStorage` 仅用于旅人印章和私人纸条，未接入服务器端留言、访客账户或公共排行榜。

## 页面
- `secrets.html`：原创四关网页解谜游戏，支持线索检查、密码、符号顺序、开关机关、星星旋律记忆、提示和本地进度。
- `postcard.html`：明信片设计器，六套配色、八款贴纸、三种纸边样式、动态预览、自定义文字、复制文字和 SVG 下载。
- `index.html` 新增互动实验区：链接两款可操作作品，并延续小屋漫游、作品展示、灵感橱窗及私人手账。
- \`index.html\`：首页、作品卡、灵感橱窗、便签筛选、开发手记、灵感签。
- \`projects/cleos.html\`：Miorune（米洛恩）项目档案，基于 Cleos 的非官方二次开发。
- \`projects/cistella.html\`：Cistella 项目档案。
- \`projects/ai-room.html\`：AI 群聊实验室项目档案。
- \`assets/site.css\`：响应式设计、日夜主题、渐入、飘浮和光影动画。
- \`assets/site.js\`：主题、进度条、低动效兼容、卡片筛选和灵感签。

## 本地查看
直接用浏览器打开 \`index.html\` 即可，或在项目根目录运行 \`python -m http.server 8000\`，访问 \`http://localhost:8000\`。

## 交互与维护
- 两个独立页面均为**无需后端的前端体验**；解谜进度、明信片草稿和私人纸条只保存在浏览器本地。无访客账户、无公共留言服务。
- 明信片下载采用浏览器内 SVG 生成；部分字体在不同设备的 SVG 查看器中可能有细微差异。
- 首页“可游玩”“可制作”仅指本站提供的小互动，不表示 Miorune（米洛恩）或 AI 群聊项目已正式发布。
- 尊重系统 \`prefers-reduced-motion\` 设置；不支持 JS 时正文依然可见。
- 夜间模式储存在浏览器本地，没有后台账号或数据上传。
- 原画展区目前使用 CSS 原创装饰图形，尚未导入独立的角色插画文件。更新时请以有权使用的本地图片素材替换并标注。
- 项目卡上的状态是创作说明，不等同于软件已正式发布。
