A LITTLE MORE ABOUT THIS PROJECT

这间小房间里有什么？

Cleos 是一项围绕私人数字空间展开的 Android 改造与扩展项目。它不只追求「功能齐全」，也在反复尝试更合手的聊天体验、主题外观与轻量小游戏。漂亮和好用，从来都不该是二选一。

IDEAS, DETAILS & EXPERIMENTS

正在打磨的部分

01 / FEATURE

聊天与交互

探索更顺手的聊天操作，包括文件、语音交互等持续完善中的能力。

02 / FEATURE

纸感主题

尝试紫雾手账、纸绘图标与波浪纸带导航，保留已有的玻璃质感风格。

03 / FEATURE

小型游戏

将井字棋一类小游戏加入交互场景，让应用不止是严肃地聊天。

04 / FEATURE

真机与反馈

在实际设备上检查键盘遮挡、导航布局、按钮可见性等细节问题。

CURRENT NOTE

现在进行到哪里了？

正在维护与迭代。不同分支和功能状态可能随开发更新而改变。
