A LITTLE MORE ABOUT THIS PROJECT

这间小房间里有什么？

Cistella 是一座为角色、聊天、记忆与世界观准备的私人数字空间。希望一个人物不再只是孤零零的对话框，而能和自己的档案、经历与设定一起被保存、整理、继续书写。它仍在不断建造中。

✧
IDEAS, DETAILS & EXPERIMENTS

正在打磨的部分

01 / FEATURE

角色与人物

为独立角色保留自己的身份、关系与设定，避免把不同人物混为一谈。

02 / FEATURE

记忆与世界书

将故事背景、长期记忆与聊天记录分开组织，便于回顾与扩展。

03 / FEATURE

本地优先

以前端存储组织个人内容，重视数据留存、备份与迁移体验。

04 / FEATURE

日常小组件

计划把相册、日记、主题与其他微小但实用的互动收进同一个空间。
